學習歷程與 AI 使用心得

學習心得

這次做作業學到了很多以前沒碰過的東西。一開始連 Git 和 GitHub 要怎麼用都搞不太清楚，後來慢慢摸懂怎麼上傳檔案和看 Commit 紀錄。練習 HTML5 和 CSS 讓我學會怎麼把網頁排版排得好看，而 jQuery 則讓網頁變得很有趣，可以做按鈕點擊和切換特效。Ajax 原本聽起來很難，但透過實際練習發送請求載入資料後，才發現其實邏輯蠻好懂的，很有成就感！

AI 工具使用心得

在這次學習過程中，AI 幫了我很多。很多程式題目都是英文看到的時候根本一頭霧水，或者網頁圖片不知道哪裡打錯時，AI 馬上找到問題在哪（像是發現是路徑多打了資料夾名稱）。平常程式碼就看得霧煞煞，如果有沒看過的寫法可以問ai解釋得很白話，還會一步一步教我怎麼改，省下非常多自己卡關摸索的時間。
